## 🔧 What I work on

- **Autonomous systems:** GPS-denied drones with ROS 2, SLAM, Nav2, YOLOv8 on Jetson; Pixhawk / EKF3 / MPC
- **Power electronics & PCB design:** KiCad, Li-Po charging, power interface boards
- **Embedded firmware:** ESP32, C, MAVLink
- **RF / microwave:** patch antennas, dielectric heating, system-level design
- **Software:** Python, JavaScript/TypeScript, full-stack web, ML pipelines
